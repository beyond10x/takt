## What

loom 0.49.0 moves its governor to Canon 0.7.0 and engineering-protocols 0.13.0; loom 0.49.1
adds ESS 0.76.0 to unpublished conformance crates only. takt's loom pin moves from 0.48.0 to
0.49.1, and engineering-protocols to 0.13.0 and Canon to 0.7.0 with it, which wave 43 deferred
because loom 0.48.0's governor compiled protocols with Canon 0.6.0.

## Breaking for a consumer

- Canon's `Protocol` is re-exported by loom.
- loom's bundled catalog carries loop-improvement@1, self-improvement@1, story-delivery@1 and
  story-delivery@2, so an installation that registers one of those names is refused.
- self-improvement@1 and story-delivery@2 declare case inputs the run defaults do not supply, so
  a run that picks either without them is refused with `MissingInput`.

## Check

```expected_before
command: grep -q 'tag = "0.49.1"' Cargo.toml && { echo "loom 0.49.1"; exit 0; } || { echo "loom older than 0.49.1"; exit 9; }
exit: 9
healthy_exit: 0
output: loom older than 0.49.1
```

## Acceptance

1. The predicate above exits 0.
2. The workspace builds with Canon 0.7.0 and engineering-protocols 0.13.0, and its tests pass.
3. `takt run --protocol protocols/story-delivery/3.yaml` runs takt's own story.delivery/3.
