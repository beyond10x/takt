## Outcome

`takt-bench journey`, a subcommand of the `takt-bench` binary (crate `crates/takt-bench`, story:baseline-runner-in-repo, clap derive), reads `docs/metrics/bench-runs.jsonl` as well as `scenario-runs.jsonl`, and draws one lane per benchmark run in `journey.svg`, grouped by arm, using the same operation vocabulary as `docs/metrics/journey.py`. A benchmark comparison can then be read on the same timeline as the scenario runs. The subcommand replaces `journey.py`, which is removed.

## Context

This was split from story:bench-free-arms, whose earlier acceptance joined the rows and the drawing. design:benchmark-integration § How takt fits a benchmark: "the journey view draws them (story:harness-journey-timeline)". Today the generator reads only `scenario-runs.jsonl` (`docs/metrics/journey.py:21`), and only scenario 1 (`docs/metrics/journey.py:811`). It takes no arguments, so a check could only run on the committed records.

The plan was to extend `journey.py`. Running code committed to this repository is Rust with clap derive (approval-record:store-replan-2026-10-28), so the extension is a Rust port with the bench input added. story:run-swimlane also retires `journey.py`, into per-run swimlanes generated by `takt-docs`; whichever of the two lands first removes the script, and the second reads the same inputs through the Rust code that is there. story:repository-scripts-are-rust counts the script among the Python it removes.

The input paths are arguments, with the committed files as the defaults, so the check runs offline on a fixture. No token or cost figure is taken from the journeys (`docs/metrics/journey.py:10`); figures stay in the rows.

## Expected before

On takt at main, holds; after the change, fails:

- `grep -rqs bench-runs crates/takt-bench/src || echo no-bench-journey` prints `no-bench-journey`.

## Scope

- `crates/takt-bench/src/main.rs`: the `journey` subcommand (inferred)
- `crates/takt-bench/tests/journey.rs` (inferred)
- `docs/metrics/journey.py`: removed (cited)
- `docs/metrics/fixtures/` (inferred)

## Acceptance

With `docs/metrics/fixtures/bench-runs-one.jsonl` (one takt-arm row whose `case_dir` names a committed fixture case), `takt-bench journey --bench-runs docs/metrics/fixtures/bench-runs-one.jsonl --out <dir>` writes `<dir>/journeys.jsonl` holding at least one line whose `run` is that row's `id`, where at fb3c3bc no such subcommand exists.

The written SVG also holds one lane per run, grouped by arm: for the fixture's one row, `grep -c 'data-arm="takt"' <out>` prints 1.

On the committed `scenario-runs.jsonl` and no bench rows, `<dir>/journeys.jsonl` holds the same runs and operations `journey.py` wrote at the base. Checked in `crates/takt-bench/tests/journey.rs` under `task test-library`.
