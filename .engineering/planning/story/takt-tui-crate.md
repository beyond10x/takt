# Story: takt-tui-crate

## Outcome

A dedicated crate, `crates/takt-tui`, holds the terminal frontend, generated by `ess generate ui --target tui` from `ess/ui/takt.ui.yaml` and never edited by hand; `takt tui --repo <path>` starts `takt serve` on a free local port and the app bound to it, and stops the server when the app quits.

## Context

epic:terminal-frontend, step 4. Depends on story:tui-ui-document and story:takt-serve-read-only. The generated crate embeds the document and its binding (beyond10x/ess `crates/ui/ess-ui-tui/src/lib.rs`, `Embedded`, `run_embedded`). A change to the frontend is a change to the document, then a regeneration; a check fails when the generated crate differs from a fresh generation.

## Expected before

On takt at main, holds; after the change, fails:

- `ls crates/takt-tui/Cargo.toml` exits non-zero.

## Scope

- `crates/takt-tui/**` (generated) (inferred)
- `crates/takt-cli/src/main.rs`: the `tui` command (inferred)
- `Cargo.toml` (workspace member), `Taskfile.yml` (a regeneration check) (inferred)

## Acceptance

`takt tui --repo <scratch repository with the recorded cases> --screen-once 120x40` prints one frame of the case list naming the improvement turn's case, `task check` fails when `crates/takt-tui` differs from `ess generate ui --target tui` output, and quitting the app leaves no `takt serve` process running.
