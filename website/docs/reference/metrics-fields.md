# Metrics fields

The figures takt is judged by are kept as a committed series in `docs/metrics/`, JSON Lines, one
object per line. The four record files are appended to and never rewritten; `journeys.jsonl` is
generated from them. What a missing figure looks like:
[Methodology](../self-improvement/methodology.md#not-recorded).

| file | one line per | fields |
|---|---|---|
| `scenario-runs.jsonl` | scenario or variety run of any arm | [scenario-runs.jsonl fields](https://github.com/beyond10x/takt/blob/main/docs/metrics/README.md#scenario-runsjsonl) |
| `improvement-turns.jsonl` | improvement turn: a finding checked before and after a fix | [improvement-turns.jsonl fields](https://github.com/beyond10x/takt/blob/main/docs/metrics/README.md#improvement-turnsjsonl) |
| `waves.jsonl` | wave merged into `main`; it holds waves 06 to 11 | [waves.jsonl fields](https://github.com/beyond10x/takt/blob/main/docs/metrics/README.md#wavesjsonl) |
| `events.jsonl` | dated event the timeline marks, with the run record it is read from; not a [case](/docs/concepts/glossary#case)'s [run record](./events-jsonl.md) | [events.jsonl fields](https://github.com/beyond10x/takt/blob/main/docs/metrics/README.md#eventsjsonl) |
| `journeys.jsonl` | operation of a run, in one vocabulary (generated by `journey.py`) | [The journeys](https://github.com/beyond10x/takt/blob/main/docs/metrics/README.md#the-journeys) |

Each field, with where its value is read from, is defined in
[`docs/metrics/README.md`](https://github.com/beyond10x/takt/blob/main/docs/metrics/README.md).
