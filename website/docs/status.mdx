# Status

0.14.0 is the latest release. It holds `takt run`, `approve`, `protocols`, `scenario run`,
`scorecard`, `trace`, `report`, `view`, `promote` and `replay`, with `story.delivery/1` and
`self.improvement/1` embedded, and prebuilt binaries for Linux (x86_64, aarch64) and macOS
(aarch64). Its harnesses are Claude Code (`--harness claude`), Codex (`codex`) and b10x-harness
(`harness`), each through a metaharness session, or `none` to run validators only.

How it got there ([changelog](https://github.com/beyond10x/takt/blob/main/CHANGELOG.md)):
