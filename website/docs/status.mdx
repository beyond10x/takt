# Status

0.1.0 is the first release. It holds `takt run`, `approve`, `protocols`, `scenario run`,
`scorecard`, `trace`, `report` and `promote`, with `story.delivery/1` embedded, and prebuilt
binaries for Linux (x86_64, aarch64) and macOS (aarch64).

| milestone | state |
|---|---|
| M1 one step validated | done 2026-10-18 |
| M2 a story end to end | built; not yet proven with the grant as the only manual step |
| unattended scenario 1 | next: accepted with one invocation plus one grant, daily for a week |
| self-improvement | phase R0: three turns accepted from records written by hand; the judge guard and validators for `self.improvement/1` are not built |
| M3 to M5 | workflows as `workflow/1` files, a second harness and the confinement seam, a week of daily runs: not built |
| continuous runs | designed, not built |
