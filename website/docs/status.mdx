# Status

0.7.0 is the latest release. It holds `takt run`, `approve`, `protocols`, `scenario run`,
`scorecard`, `trace`, `report`, `view`, `promote` and `replay`, with `story.delivery/1` and
`self.improvement/1` embedded, and prebuilt binaries for Linux (x86_64, aarch64); it has no
macOS binary (on macOS use 0.6.0 until 0.7.1). Its harnesses are Claude Code (`--harness claude`), Codex (`codex`) and b10x-harness
(`harness`), each through a metaharness session, or `none` to run validators only.

How it got there ([changelog](https://github.com/beyond10x/takt/blob/main/CHANGELOG.md)):

| release | what it added |
|---|---|
| 0.1.0 | the first release: `run`, `approve`, `protocols`, `scenario run`, `scorecard`, `trace`, `report` and `promote`, with `story.delivery/1` embedded |
| 0.2.1 | the 0.2 line (0.2.0 was tagged, not published): the judge guard, and `self.improvement/1` turns that end `unreproducible` or `declined` |
| 0.2.2 | a turn reaches `accepted` on validators' records: the merge validators and `binary.promote` |
| 0.2.3 | a Claude step is offered only the tools it may use (`--tools` beside `--allowedTools`): on scenario 1 with one fixed prompt, a step's first request fell from 12,554 to 5,550 prompt tokens |
| 0.3.0 | a promotion judged against the start of its series and on every scenario either side has; the `Unperformable` and `DiskLow` stops; each harness step's transcript kept |
| 0.4.0 | `takt view`; one commit identity on every commit takt makes; a `--forge none` delivery handed over as a candidate |
| 0.5.0 | `takt replay`; the `--active-seconds` budget and its `ActiveTime` stop; `takt scorecard --steps`, judging the steps a candidate targets |
| 0.6.0 | a run records the layers it ran on, and `takt report` attributes tokens, cost and time to them; a run whose harness step recorded no tokens has unknown tokens, never a sum that counts the step as 0 |
| 0.7.0 | every harness runs through one metaharness session, and `--harness` takes `codex` and `harness` beside `claude`; the harness's change comes back as a proposal, which takt writes to the case's tree only after the step guard admits it |
