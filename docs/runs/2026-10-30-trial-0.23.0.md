# Trial of takt 0.23.0: scenario 1 stops on the token budget

One trial cycle on release 0.23.0 (tag `0.23.0`, `f6fb9c85655e21f17acd2a1fbca5de1b6d2c42c0`),
2026-10-30 (UTC), under `.agents/trial-agent.md`. Every figure is read from a command of the
cycle: `takt scenario run`'s `stopped:` lines, `takt scorecard`, `takt report`, the cases'
`events.jsonl` and the step transcripts. The records are kept outside the repository.

## The runs

| run | case | stop | steps | tokens | tests.write | implementation.edit | change.handover |
|---|---|---|---|---|---|---|---|
| 1 | `scenario-1-trial-359` | `Tokens (49030)` | 9 | 54,415 | 20,275 | 23,850 | 10,290 |
| 2 | `scenario-1-trial-360` | `Tokens (49030)` | 9 | 52,065 | 20.5k | 21.3k | 10.3k |

Both runs wrote a test and the code, passed the tests and the gate, and handed over; the budget
then stopped them before `pr.open`, so neither opened a pull request and the held-out check of
the scorecard failed. The same check on each case's head passed. Two cases ranked below the
baseline's decide "worse" at 5 trials and a margin of 1, so the set stopped after run 2.
`takt scorecard --against` the baseline gives no verdict on 2 cases (exit 1, `too few cases (2 of
5)`).

The baseline's steps were tests.write 17,864 to 18,025, implementation.edit 20,901 to 21,134 and
change.handover 9,854 to 9,951. Run 1's prompts were 4,295, 10,209 and 9,796 bytes at steps 3, 6
and 9 against 2,059, 3,620 and 6,243 in the baseline's first run. A set on Claude Code 2.1.309
with takt 0.10.1 measured the first call of step 3 at 8,146 tokens, the baseline at 8,151 and this
release at 9,329: the growth is takt's prompt, not the harness.

## What grew

- The repository's instruction files, AGENTS.md and CLAUDE.md, given to every step as context
  files: 1,147 bytes a call.
- A failed test run and a failed gate that runs the same tests show the same failing tests, their
  assertion locations and the paragraph after them twice: about 1,085 bytes in the call after
  them.
- The list of actions not admissible ends each line with the protocol's whole description of the
  action: 618 bytes in every call on scenario 1.
- The commit paragraph (612 bytes), the decline paragraph (252 bytes) and the longer
  implementation wording (244 bytes).
- `change.handover` changes no file and costs about 10,300 tokens, 4,780 of them Claude Code's
  own system prompt and tool schemas, which a choice needs none of.
